## The platform

**FixMate brings everyday home services into one connected experience.** From plumbing and electrical work to cleaning, air-conditioning maintenance, furniture moving, painting, and garden care, the platform is designed to make it easier to discover services, find professionals, and coordinate work.

Built with the Jordanian market in mind, the experience supports **Arabic and English**, **Jordan's governorates**, and service pricing displayed in **Jordanian dinars (JOD)** when available.

> **Our focus:** straightforward service discovery, useful workflows, and a product that feels accessible to everyday households rather than a luxury-only audience.

## Technology

FixMate follows a separated frontend-and-API architecture with MongoDB persistence.

<div align="center">
  <strong>Angular application &nbsp; &rarr; &nbsp; NestJS REST API &nbsp; &rarr; &nbsp; MongoDB</strong>
</div>

<br />

| Layer | Technologies |
| :--- | :--- |
| **Frontend** | Angular 22, TypeScript, SCSS, Signals, RxJS |
| **Backend** | NestJS 11, Node.js, TypeScript, REST APIs |
| **Database** | MongoDB 7, Mongoose |
| **Access & security** | JWT, rotating HttpOnly refresh sessions, bcrypt, role-based authorization |
| **Development & QA** | Docker Compose, Git, Jest, Vitest, Playwright |

Our development approach emphasizes **maintainable code, readable interfaces, localization, and meaningful automated verification**.
